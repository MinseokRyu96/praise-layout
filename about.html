About

찬양팀을 위한 A3 악보 정리 도구

PraiseLayout은 예배 콘티에 맞춰 여러 곡의 악보 이미지를 A3 한 장 또는 여러 장으로 배치하고, PDF와 JPG 파일로 내려받을 수 있도록 만든 웹 도구입니다.

무엇을 해결하나요?

찬양팀은 예배 전에 곡 순서, 악보, 흐름 메모를 빠르게 정리해야 합니다. PraiseLayout은 곡 정보와 악보 이미지를 한 화면에서 입력하고, A3 출력에 맞는 레이아웃으로 미리보기와 다운로드를 제공합니다.

현재 제공 기능

  • 예배 날짜와 콘티명을 기준으로 파일명 자동 생성
  • 곡별 제목, 흐름 메모, 악보 이미지 업로드
  • A3 가로와 세로 방향 선택
  • 장당 곡 수와 여백 조정
  • PDF 다운로드와 페이지별 JPG 다운로드

파일 처리 방식

업로드한 악보 파일은 사용자의 브라우저에서 미리보기와 다운로드 생성을 위해 사용됩니다. 현재 MVP 버전은 별도 서버에 악보 파일을 저장하거나 공유하지 않습니다.
